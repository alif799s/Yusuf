Jaringan Komputer

Jaringan komputer adalah sistem yang menghubungkan dua atau lebih perangkat komputasi—seperti komputer, laptop, ponsel, server, atau printer—melalui media kabel maupun nirkabel untuk saling berkomunikasi, bertukar data, dan berbagi sumber daya menggunakan aturan komunikasi (protokol).

Fungsi Utama Jaringan Komputer dan Manfaatnya

Fungsi utama jaringan komputer adalah memungkinkan beberapa perangkat saling terhubung untuk berbagi sumber daya, bertukar data, dan berkomunikasi secara efisien.

1

Berbagi Sumber Daya (Resource Sharing)

  • Perangkat keras (hardware): Beberapa komputer dapat memakai satu printer, scanner, atau media penyimpanan (NAS) secara bersama-sama tanpa perlu membeli alat untuk setiap komputer.
  • Koneksi internet: Satu jaringan internet utama (misalnya dari satu router Wi-Fi) dapat dibagikan ke banyak ponsel, laptop, dan perangkat lain sekaligus.
  • Perangkat lunak (software): Aplikasi atau sistem tertentu dapat dipasang di server pusat lalu diakses oleh banyak pengguna secara bersamaan.
2

Pertukaran dan Akses Data (Data Sharing)

  • Transfer file cepat: Pengguna dapat mengirim dokumen, foto, atau video antarperangkat secara langsung lewat jaringan lokal maupun internet tanpa memakai flashdisk.
  • Penyimpanan terpusat: Data penting dapat disimpan di satu server atau cloud sehingga mudah diakses oleh tim yang berwenang dari mana saja.
  • Sinkronisasi data: Perubahan pada data (seperti stok barang di kasir atau dokumen kerja bersama) langsung diperbarui secara real-time untuk semua pengguna yang terhubung.
3

Komunikasi dan Kolaborasi

  • Komunikasi instan: Mendukung pengiriman pesan teks (email, chat), panggilan suara (VoIP), hingga konferensi video (video call).
  • Kerja jarak jauh (remote work): Memungkinkan karyawan atau pelajar mengakses sistem kantor, kampus, maupun ruang kelas daring dari lokasi berbeda.
4

Efisiensi Biaya dan Pengelolaan

  • Menghemat anggaran: Berbagi perangkat keras, lisensi perangkat lunak, dan penyimpanan terpusat menekan biaya pembelian serta perawatan.
  • Manajemen terpusat: Administrator jaringan dapat mengatur pembaruan sistem, mencadangkan data (backup), dan memantau seluruh perangkat dari satu pusat kendali.
5

Keamanan dan Kontrol Akses

  • Pembatasan hak akses: Pemilik jaringan dapat menentukan siapa saja yang boleh melihat, mengubah, atau menghapus data tertentu.
  • Perlindungan data: Jaringan memudahkan penerapan firewall, enkripsi, dan pencadangan rutin agar data tetap aman dari kerusakan perangkat maupun akses tidak sah.

Materi yang Dipelajari

  • Pengalamatan IP (IPv4), Subnetting, dan Gateway
  • Konfigurasi Router MikroTik (DHCP, NAT, Firewall, Simple Queue)
  • Media transmisi kabel (UTP/RJ45) dan nirkabel (Wi-Fi/Access Point)
  • Protokol komunikasi jaringan seperti TCP/IP, DNS, HTTP/HTTPS
  • Troubleshooting koneksi dan pengujian jaringan

Mikrokontroler

Mikrokontroler adalah komputer berukuran kecil dalam satu chip terpadu yang dirancang untuk mengendalikan perangkat elektronik, membaca input dari sensor, dan menggerakkan aktuator seperti LED atau motor secara otomatis.

Materi yang Dipelajari

  • Pengenalan papan mikrokontroler Arduino Uno dan pin I/O
  • Pembacaan data jarak menggunakan sensor ultrasonik HC-SR04
  • Pengendalian indikator LED dan komponen output digital
  • Penulisan logika pemrograman mikrokontroler berbasis C/C++
  • Perakitan rangkaian elektronika dasar pada breadboard

Tentang Proyek

Sensor ultrasonik HC-SR04 memancarkan gelombang suara dan menghitung waktu pantulannya untuk mengetahui jarak sebuah objek.

Arduino membaca data tersebut, mengubahnya menjadi jarak (cm), lalu menampilkannya secara real-time sehingga perubahan jarak langsung terlihat.

Yang Dikerjakan

  • Pengukuran jarak objek secara real-time
  • Rangkaian sederhana dan mudah dikembangkan
  • Program Arduino (C++) yang rapi dan dikomentari
  • Bisa dikembangkan jadi alarm jarak atau sensor parkir

Proses Pengerjaan

1

Merakit rangkaian

Menghubungkan pin VCC, GND, Trig, dan Echo sensor ke Arduino.

2

Menulis program

Mengirim sinyal trigger, membaca durasi echo, lalu menghitung jarak.

3

Menampilkan hasil

Menampilkan nilai jarak secara real-time dan memeriksa ketelitiannya.

4

Kalibrasi & uji

Membandingkan hasil sensor dengan pengukuran penggaris pada beberapa jarak.

Tantangan & Solusi

Pembacaan jarak sering loncat-loncat

Solusi

Ditambah pembacaan berulang dan perataan nilai supaya hasil lebih stabil.

Hasil

  • Sensor berhasil membaca jarak dengan cukup akurat
  • Pemahaman dasar tentang sensor, pin digital, dan pemrograman Arduino

Yang Dipelajari

  • Cara kerja sensor ultrasonik
  • Dasar pemrograman Arduino (C++)
  • Merangkai komponen elektronik dengan benar

Konfigurasi MikroTik

Konfigurasi jaringan dan routing menggunakan router MikroTik untuk kebutuhan lab jaringan sekolah, mencakup pengaturan IP, firewall dasar, dan manajemen bandwidth antar client.

Peran

Konfigurasi & Troubleshooting

Durasi

1 bulan

Tahun

2026

Status

Selesai

Tentang Proyek

Proyek ini berawal dari kebutuhan lab jaringan sekolah: client harus bisa saling terhubung, dapat IP otomatis, dan tetap bisa internetan tanpa satu perangkat pun menghabiskan seluruh bandwidth.

Router MikroTik dipakai sebagai pusat jaringan — mengatur alamat IP, membagikan IP lewat DHCP, meneruskan trafik ke internet lewat NAT, memfilter trafik lewat firewall, dan membatasi bandwidth tiap client.

Yang Dikerjakan

  • Pengalamatan IP & pembagian segmen jaringan lab
  • DHCP Server supaya client dapat IP otomatis
  • NAT (masquerade) untuk akses internet
  • Firewall dasar untuk mengamankan router dari akses yang tidak perlu
  • Simple Queue untuk manajemen bandwidth antar client

Proses Pengerjaan

1

Reset & akses awal router

Menyiapkan router dari kondisi bersih, lalu masuk lewat Winbox untuk mulai konfigurasi.

2

Pengaturan IP Address

Menentukan IP untuk interface WAN dan LAN sesuai rancangan jaringan lab.

3

DHCP Server & DNS

Membuat pool IP, mengaktifkan DHCP server, dan mengatur DNS agar client langsung bisa browsing.

4

NAT & Routing

Menambahkan rule masquerade dan default route supaya trafik lab keluar ke internet.

5

Firewall & Bandwidth

Menyusun rule firewall dasar dan Simple Queue, lalu menguji hasilnya dari beberapa client.

Tantangan & Solusi

Client sudah dapat IP tapi tidak bisa internetan

Solusi

Dicek bertahap dari gateway, DNS, sampai rule NAT — ternyata rule masquerade belum mengarah ke interface yang benar.

Bandwidth tidak merata antar client

Solusi

Diatasi dengan Simple Queue agar tiap client mendapat jatah yang adil.

Hasil

  • Seluruh client lab terhubung & dapat internet stabil
  • Bandwidth terbagi lebih merata
  • Dokumentasi konfigurasi bisa dipakai ulang untuk praktik berikutnya

Yang Dipelajari

  • Alur kerja jaringan dari IP, DHCP, NAT sampai firewall
  • Cara troubleshooting jaringan secara berurutan
  • Dasar-dasar persiapan sertifikasi MikroTik (MTCNA)
